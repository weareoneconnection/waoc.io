# WAOC V10 Architecture

## Brand responsibility

- `weareoneconnection.org`: theory and manifesto
- `waoc.io`: living coordination network
- `oneai.network`: intelligence infrastructure and products

## Experience primitives

- **Node**: a participant or system
- **Line**: a relationship or handoff
- **Orbit**: a durable relationship
- **Field**: a shared coordination context
- **Pulse**: a signal, state change or opportunity

## System relationship

WAOC builds the network.
OneAI Labs builds the intelligence infrastructure.
OneField connects both through shared memory, evidence, identity and reputation.

## Performance strategy

- Single fixed WebGL scene instead of multiple canvases
- Device pixel ratio capped at 1.6
- No post-processing dependency
- Native CSS and DOM animations
- Reduced-motion fallback
- Content remains readable if WebGL fails
